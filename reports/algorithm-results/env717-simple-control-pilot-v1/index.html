Simple control: finite-action pilot

This first source-attributed slice adapts the discrete SimpleControlProblem to a four-step terminal minimax problem. The solver exhausts all 81 action sequences; an independent Python enumeration checks every saved trajectory and the ten near-optimal plans under absolute tolerance 1e-14. One warmup and seven measured solver calls are recorded; setup and JSON output are excluded.

Scope: the source defaults to initial state [0, 1] and terminal time 2 s. This pilot uses x₀ = 0.1 and 0.2 s to keep exhaustive enumeration small. It minimizes terminal x² and omits the source running reward. The source also has different running-reward coefficients in cost() and step(); the source step() execution rule is the reference for the environment. This is not a reproduction of the original reward objective.
