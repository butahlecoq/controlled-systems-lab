Van der Pol finite-action pilot

This report re-expresses the pinned upstream Van der Pol equations and task notebook at commit f4d76c60f4003f50954174e96eafd8e514bd5441. The state is time, position, and velocity. Each 0.1-second source action uses ten explicit-Euler substeps.

Source limitation: the upstream step() mutates state and then raises NameError because its return tuple references undefined _. This report independently replays the documented update equations and reward; it does not claim to run the broken Python environment.
Adaptation: the source has continuous scalar controls. This pilot enumerates five open-loop macro controls chosen from [-1.0, 0.0, 1.0], held for 22 source steps each. The minimum is over all 243 plans only; it is not a continuous-action optimum, minimax value, or performance comparison.
