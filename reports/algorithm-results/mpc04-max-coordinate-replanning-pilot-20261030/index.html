MaxCoordinateGame: finite closed-loop MPC comparison

Nominal and finite-catalogue minimax controllers repeatedly plan, execute one action, observe the next state, and replan on a source-derived RL environment.

Scope. Four scored steps, controls and disturbances in {−1,+1}, all 16 complete disturbance histories, and the source 100-substep transition. This is a finite adaptation of the continuous-action four-second RL environment. It establishes results only for this finite catalogue; calculations use binary64 arithmetic with tolerance-based independent replay.

Evidence

  • Independent checker replays all 256 state transitions, verifies the complete 16-history catalogue for each of four variants, recomputes each chosen plan value, and checks the original terminal score.
  • Forced deadline and solver-failure fixture episodes confirm that the runner applies the explicit zero-control fallback, continues to the episode endpoint, and counts every fallback.
  • The driver executes the authored finite policy-gap fixtures and checks fixed-plan/replanning/causal values 2/2/1 and scalar fixed-plan/replanning values 2/0.
  • No state constraints are present in this source-derived slice; controls remain in the authored source bounds.
  • No recursive-feasibility, stability, continuous-disturbance, or global causal-optimality theorem is claimed.
