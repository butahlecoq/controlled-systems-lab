Analytic fixture

x[t+1] = x[t] + u[t], x[0] = 0, 0 <= u[t] <= 1; minimize x[T].

Because x[T] = sum(u[t]), the exact optimal value is 0, attained by the all-zero history. The checker verifies each relation includes that history, contains the initial, transition, and control-bound rows, and imposes x[T] <= 0 (or equality). Together with x[T] = sum(u[t]) and u[t] >= 0, these conditions force the relation to be exactly the singleton all-zero optimum for these fixtures. This is a fixture-specific independent proof; neither strategy's general candidate-family completeness is inferred.
