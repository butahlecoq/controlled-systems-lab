DubinsCar finite open-loop pilot

This report re-expresses the pinned DubinsCar terminal environment. The state is time, x position, y position, and heading. The model applies 20 explicit-Euler updates per 0.1-second source action step.

Scope: the source allows a new continuous control every source step. This pilot uses three open-loop control choices, each held for 21 source steps, and checks all 125 plans. The reported minimum applies only to that finite catalogue. It is not a continuous-action optimum or a minimax result.

Reproduce and inspect

From the repository root, configure and build the standalone report project:

cmake -S benchmarks/reporting/env717/dubins-car-build -B build/env717-dubins-car -DBUILD_TESTING=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build/env717-dubins-car --config Release --target csl_env717_dubins_car
python3 scripts/reports/env717/check_dubins_car.py build/env717-dubins-car/csl_env717_dubins_car

The checker independently replays every finite plan.
