Controlled Systems Lab · EXT-07

2D joint-relation example

The axes show the joint relation between one scalar control and the terminal state.

Input and analytic result

The state dimension is one and the horizon is one stage, from time 0 to time 1. The initial mode is coast at stage 0, with scalar state x₀=0. There are two modes (coast and terminal) and one permitted edge coast-to-terminal from coast to terminal at the boundary between stages 0 and 1. The allowed terminal set is the singleton {terminal}, active at stage 1. Both mode invariants are universal sets (they impose no additional state restrictions). The source-mode flow is x_pre=x₀+u₀, with control u₀∈[0,1]. The stored terminal-mode flow has A=1, B=1, offset=0 and a universal control set; it is inactive because the horizon ends at stage 1. There are no external channels, observations, or temporal constraints. The transition guard requires x_pre∈[0,0.5]; the one-dimensional identity reset sets x₁=x_pre. The terminal objective is minimize x₁. The full joint relation is x₀=0, x_pre=u₀, x₁=u₀, 0≤u₀≤0.5. Its complete minimizer family is the point (x₀,u₀,x_pre,x₁)=(0,0,0,0).
