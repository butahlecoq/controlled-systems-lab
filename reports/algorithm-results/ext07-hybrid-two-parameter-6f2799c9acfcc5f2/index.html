Controlled Systems Lab · EXT-07

Two-parameter hybrid family verification

Measured public path construction, two-branch optimization, and complete-family verification for one fixed two-stage scalar fixture.

Analytic answer

The enter-half path has feasible controls [0,0.5]×[0,1]; enter-full has [0,1]×[0,1]. Both minimize x_terminal=u₀ at zero, retaining the complete tied families u₀=0, 0≤u₁≤1.

Open the standalone two-control example (includes a labelled plot, fixture, independent answer, and reproduction commands).

Measured execution

One excluded 10-call warmup followed by seven measured batches of 20 calls: 140 measured calls, no failures. Median batch duration is 71,092,237 ns (range 69,834,803–81,970,034 ns); median individual call is 3,528,795 ns. Each end-to-end interval includes fixture/provider setup, complete two-path relation assembly, both HiGHS LP solves, tied-face construction, and verification of both path families. CTest and build time are excluded.

Scope and provenance

This is descriptive evidence for one Linux measurement workstation Release host and one analytic fixture. It makes no comparison, speedup, source-mapped bottleneck, or scalability claim. It covers exactly two scalar free controls; larger polytope dimensions and general horizons remain unmeasured. Assurance is numerical binary64, not validated arithmetic.
