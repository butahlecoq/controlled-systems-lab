QuickHull and ITIS17-related LP hull pilot

Preliminary exploratory result · source commit 4494557aad4710fe1166b5a681057f106ef8fb91

Performance conclusion: inconclusive. This run used three tiny 2D square clouds. It has no source-mapped limiter profile or representative end-to-end workload, so the measurements do not support a speed ranking or scalability claim.

Algorithms and timing scope

All 96 calls (12 warmups and 84 measured calls) passed the fixture checks. Passing these small cases does not establish general correctness for arbitrary point clouds. The reducers can retain different numbers of redundant points while representing the same hull.

Evidence and limits

  • Three literal clouds contain 5–10 points each.
  • The oracle checks point accounting, exact-binary64 convex-combination evidence for deleted points, rectangle containment, and retention of all four expected corners.
  • All algorithms ran in Release on GCC 16.2.1, C++20, HiGHS 1.11.0, Linux x86_64.
  • No original Pascal source for the ITIS17 methods was found. The separate btulshor.pas method was not run.
  • This is an exploratory, unregistered bundle. It does not complete issue #423 or establish a paper-faithful comparison. It is not deployed to GitHub Pages.
