EXP-02: first 4D hull-ladder cell

The workload has five 4-simplex corners and 245 dyadic interior points. Halton bases 2, 3, 5, and 7 deterministically select strictly positive barycentric weights in multiples of 1/8, making interior-point removal certificates exactly representable. Five LP reducers ran with one warmup and five measured calls each. An independent exact-rational validator checks each removal certificate and its acyclic expansion to the retained source points. A checked certificate chain is diagnostic evidence when the reducer reports incomplete status; only a complete reducer with a valid chain is labelled verified.

QuickHull is recorded as unsupported because the registered geometric implementation is 2D-only. The six plotted projections show input points only; red markers identify the 4-simplex corners.

Scope limits

  • One deterministic 250-point fixture; this is the first ladder cell, not the EXP-02 matrix.
  • These reducers are implementation variants; A43/A44 are paper-informed adaptations, not faithful ports.
  • Workspace creation and independent checking are outside reducer timing. HiGHS is pinned; native solver threading is disabled.
  • Timing is descriptive. No comparative speedup is claimed because no source-mapped limiter profile is available.
  • Raw JSONL preserves every attempt and unsupported outcome. Incomplete reducer status remains inconclusive even when partial certificates pass exact diagnostics. See validated rows and CSV.
