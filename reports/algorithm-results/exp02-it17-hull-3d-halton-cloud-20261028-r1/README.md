# EXP-02: initial pure-Halton 3D hull attempt

This preserved exploratory attempt uses 250 unscrambled Halton points in three dimensions (bases 2, 3, and 5). Five LP reducers each received one warmup and five alternating measured calls; geometric QuickHull is recorded unsupported in 3D. All measured outputs passed the exact removal-certificate-chain hull-equivalence check, but every reducer retained all 250 points. Four reducers reported incomplete status, while basis reuse returned the input unchanged with no LP calls. Therefore this cloud did not exercise vertex reduction and its timings are retained only as diagnostic data. The later [tetrahedron plus dyadic interior fixture](../exp02-it17-hull-3d-simplex-20261028-r1/index.html) is the informative 3D pilot.

The record was built from source commit `30ce2afe`, GCC 16.2.1 Release, HiGHS 1.11.0, and Linux x86_64. The raw JSONL, executable SHA256, run limits, exact validated rows, CSV and input projection figure remain in this folder. The independent hull check proves the returned input hull was preserved; it does not claim any reducer removed a point.
