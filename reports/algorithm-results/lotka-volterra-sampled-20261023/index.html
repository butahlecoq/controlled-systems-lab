A deterministic geometry illustration

Lotka–Volterra reachability samples

This example follows a discrete controlled prey–predator recurrence for 60 stages and plots 512 seeded control histories. Their state samples trace an orbit around the unforced equilibrium; four zoomed panels show sample clouds at selected stages.

Evidence scope. These are samples, not the full reachable sets. A sampled cloud may miss feasible states, and each dashed outline is only the convex hull of the displayed samples. Neither hull is an inner or outer certificate. This authored calculation does not reproduce L05 Figure 1 or Table 1, and does not run a repository synthesis algorithm, optimizer, or benchmark.

Recurrence and inputs

x1[k+1] = x1[k] + h*(a*x1[k] - b*x1[k]*x2[k] + e*u[k])
x2[k+1] = x2[k] + h*(-c*x2[k] + d*x1[k]*x2[k])
  • Parameters: a=0.9, b=0.003, c=0.8, d=0.002, e=0.85.
  • Step: h=2π/(60√(ac))=0.123413414948843; this convention is explicit for this illustration.
  • Initial state: (410, 300); control at each stage: u∈[-0.3, 0.3].
  • Sampling: 512 histories from Python random.Random, seed 20261023; one uniform draw per stage and history.
  • Units are not specified in the source; axes preserve its state coordinates without assigning physical units.
