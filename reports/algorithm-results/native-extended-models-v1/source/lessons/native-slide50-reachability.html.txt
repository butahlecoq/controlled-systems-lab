<p>The box has eight authored corners. At each transition, both control coordinates vary independently over [−1,1]; a fresh pair of control factors is added. The two registered variants show five transitions (six stage sets) and the literal printed update range k=0,…,5 (six transitions, seven stage sets). Time and state units are unspecified.</p></section>
<section><h2>Full-state propagation, then projection</h2>
<p>The native implementation propagates complete three-dimensional point sets using the registered affine-image and Minkowski-sum operations, then converts to vertices for checking and display. A separate long-double recurrence checks every mapped full-state cube corner against all stages. The saved run covers 54,608 full-state corner comparisons across the five- and six-transition variants. This is finite numerical evidence, not a validated rounding enclosure.</p>
