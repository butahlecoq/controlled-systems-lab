<p class="eyebrow">Native C++ · nine states · three controls · synthetic parameters</p><h1>A corrected spatial model, linearized along a reference</h1>
<p>The private draft supplies rigid-body Newton/Euler equations and a body-frame direction-cosine matrix, but no reproducible aircraft calibration, reference, initial set or time grid. Its final printed rows contain inconsistencies. This native case derives a B-consistent nonlinear RHS from the earlier equations, then assigns every numerical parameter and set explicitly. It is a corrected synthetic variant, not a historical reproduction or calibrated vehicle.</p>

<p>Use state order <code>(vₓ,vᵧ,v_z,φ,ψ,θ,ωₓ,ωᵧ,ω_z)</code>: body velocity in m/s, angles in rad, body angular velocity in rad/s. <p>The inertial convention is Y-up with <code>g<sub>I</sub>=(0,−g,0)</code>. Here <i>α</i> and <i>β</i> are computed from body velocity by the equations above. The implementation rejects each RHS/Jacobian evaluation unless <code>vₓ&gt;1 m/s</code> and <code>|cos ψ|≥0.2</code>; it does not clamp singular angles. These pointwise checks do not certify the entire linear reachable set against the nonlinear domain.</p></section>

<section><h2>Reference versus deviation reachability</h2>
<p>The nonlinear physical reference uses 20 intervals of 0.05 s. Classical RK4 takes ten fixed 0.005 s substeps per interval, with domain checks at every RHS evaluation (800 evaluations total). At each of the 21 endpoints, native Jacobians of this same RHS define a zero-offset, piecewise-linear time-varying deviation system. The existing LTV discretizer uses its own adaptive RK4 step-doubling; its local error receipt is separate from the fixed reference recipe and is not a certified global error bound.</p>
<p>State names in the catalogue are <code>delta_vx, delta_vy, delta_vz, delta_phi, delta_psi, delta_theta, delta_omega_x, delta_omega_y, delta_omega_z</code>; control names are <code>delta_u0..delta_u2</code>. These describe zero-centered perturbations around the physical reference, not its absolute coordinates. Initial perturbation radii are <code>(0.1,0.02,0.02,0.001,0.001,0.001,0.0002,0.0002,0.0002)</code> in the corresponding units. Each interval has a fresh independent control perturbation box with radii <code>(0.001,0.001,0.001)</code> rad.</p>
