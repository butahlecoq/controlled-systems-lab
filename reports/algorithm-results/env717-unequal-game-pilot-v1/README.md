# UnequalGame finite-action minimax pilot

Source-attributed adaptation of the upstream UnequalGame differential game. This report uses a three-stage finite action catalogue over 0.15 seconds; the source uses continuous controls over two seconds. The captured result is an open-loop fixed-plan minimax value, not the continuous-action RL result.

Upstream commit: `f4d76c60f4003f50954174e96eafd8e514bd5441`. Source blob: `a05c7caafa8c36b44f75a8c3e3355677419af6c4`. No license is declared by the upstream repository; this report re-expresses the equations and does not copy its implementation.
