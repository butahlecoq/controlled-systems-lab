EarthOrbitalMotion finite-catalog control pilot

This is a source-equation adaptation of the upstream nonlinear orbital-control environment. It uses 729 open-loop plans from a three-block finite action catalog. It is exact only over those plans and inputs; it is not an optimum over continuous controls or feedback policies.

Source: pinned upstream file, commit f4d76c60f4003f50954174e96eafd8e514bd5441, blob ce97d9d223a6ba6d02ce9a8f6a2fba26ef0fdd7d. The source repository has no declared license; the equations are re-expressed, not copied.

Timing scope

Release enumeration median 56.701 ms over 7 repetitions (range 56.646–56.949 ms). The timer includes full plan decoding, RK4 propagation and scoring, and excludes export and independent replay. A separate, unreported process probe used 99.8% CPU, consistent with compute-bound integration. This is descriptive for one small finite catalog, not a comparison or performance claim.

Reproduction

Build csl_env717_earth_orbit with CSL_BUILD_ENV717_REPORT=ON, then run python3 scripts/reports/env717/check_earth_orbit.py <driver> --output <directory>. The checker independently replays all 729 plans, writes the JSON evidence, phase-plane SVG and SHA256 manifest.
