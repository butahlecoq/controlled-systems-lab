Two points on parallel lines: reachability and minimax

The finite-action minimax method exhausts 27 fixed control plans and all 27 adversarial disturbance vertex sequences per plan. An independent Python replay checks every plan score, minimizing plan, source-integrator trajectory, forward reachable polytopes, and backward vertex-game nodes. The two panels are the physical phase planes `(x1,x2)=(position₁, velocity₁)` and `(x3,x4)=(position₂, velocity₂)`.

Adaptation: the source uses continuous actions over 10 seconds. This pilot uses a 3-stage control catalogue and disturbance sets equal to the convex hull of the listed vertices. The discrete linear stage map is derived from the source’s ten explicit-Euler substeps. The minimax solver selects an open-loop control sequence against the full convex disturbance sets. Forward polygons exactly project each convex disturbance-reachable polytope for one fixed control prefix. The separately computed backwards nodes permit state-dependent controls in a finite vertex game; they are not complete continuous-state predecessor sets or the fixed-plan solver’s output. This is not a reproduction of the original continuous-control RL experiment.
