Model and limits

  • Upstream repository: imm-rl-lab/optimal_control/Environments, commit f4d76c60f4003f50954174e96eafd8e514bd5441, source blob 4e71bed8ceffa1990645fb85e54d6b5b1eeb688d. No upstream source code is copied.
  • Upstream task uses continuous controls over 10 seconds. This report uses three stages (0.3 seconds) with control values [-2.5, 0.0, 2.5] and disturbance values [-1, 0, 1]; it is not an RL reproduction.
  • Objective: terminal squared position gap. It is monotone-equivalent to the source absolute-gap reward for policy ordering, but this report gives squared-cost units.
  • Claims cover only exact full-state observation and the listed finite disturbance catalogue. They do not cover continuous disturbances, state approximation, or the original continuous-control policy.
  • The current finite-feedback report is a safety-threshold result. This report separately solves the cost-optimal causal policy.
