Method identity and validation

A43 and A44 are paper-informed C++ adaptations, not faithful paper ports. No corresponding Pascal source was recovered from the available local search. The A43 row uses a certificate-safe basis adaptation; A44 uses incremental membership with a final recheck. The driver checks complete point accounting, verifier identity, the exact source-index hull checker, and all four expected square corners. It does not independently replay each removal certificate.

For LP methods, workspace creation occurs before timing. The timer covers the reducer call and excludes workspace setup and validation. QuickHull is timed around its call, then checked. HiGHS is configured for one thread; observed OS thread count was not recorded. A separate top run showed one logical CPU near saturation and about 8.8 MiB RSS, but no source-function profile was available. These boundaries do not establish an end-to-end winner.
