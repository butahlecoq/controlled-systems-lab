TimeOptimalSphereGame: finite-catalogue minimax reachability

This report replays the source's two-player time-to-target task on a finite action catalogue using CSL's finite-feedback reachability and finite-causal minimax solvers.

Scope and information pattern. The upstream model uses continuous actions u,v ∈ [-1,1] and trains u to minimize elapsed time while v maximizes it; both source policies use the current state without receiving the opponent's current action. This pilot discretizes both actions to {-1,0,1} and uses a sequential-response game: v observes u's action before choosing a disturbance. It runs a finite horizon of 35 decisions at 0.1 s per decision. The value and winning set apply to this adapted information pattern, not the source RL game; this is also not a continuous-action guarantee.
