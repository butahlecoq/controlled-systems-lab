Input and analytic result

The state dimension is one and the horizon is one stage, from time 0 to time 1. The initial mode is coast at stage 0, with scalar state x₀=0. There are two modes (coast and terminal) and one permitted edge coast-to-terminal from coast to terminal at the boundary between stages 0 and 1. The terminal mode is active at stage 1. Both mode invariants are universal sets (they impose no additional state restrictions). There are no external channels, observations, or temporal constraints. The source-mode scalar flow is x_pre=x₀+u₀, with control u₀∈[0,1]. The transition guard requires x_pre∈[0,0.5]; the one-dimensional identity reset sets x₁=x_pre. The terminal objective is minimize x₁. The full joint relation is x₀=0, x_pre=u₀, x₁=u₀, 0≤u₀≤0.5. Its complete minimizer family is the point (x₀,u₀,x_pre,x₁)=(0,0,0,0).

Reproduce

From a clean report-tools checkout with CMake 3.31.6, fetch the frozen implementation commit and create a separate source worktree:

git fetch origin pull/472/head:refs/remotes/origin/ext07-source
git worktree add --detach <frozen-source> 2965baafa325550ad60ec91d44f5e3f86a832178
python scripts/reports/ext07/capture.py --source <frozen-source> --capture <fresh-capture> --commit 2965baafa325550ad60ec91d44f5e3f86a832178 --cmake cmake
python scripts/reports/ext07/ext07_collect.py --capture <fresh-capture> --source <frozen-source> --out <fresh-output>
