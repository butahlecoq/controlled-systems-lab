Method

Each measured attempt constructs a fresh resolved problem, unit-box terminal slice, provider registries and prepared providers, then calls solve using one configured worker/thread. One warmup is excluded per fixture. Seven measured rounds alternate forward and reverse fixture order. All attempts and non-success outcomes remain in the raw records. Independent literal validation runs after the executable exits and is not timed as an algorithm interval. The shifted residual provides an unestablished primal witness value only; it is not reported as an optimum.
