MaxCoordinateGame: reachability and minimax

CSL finite-action minimax solves the source oscillator on a short finite action catalogue. The source reward max(|y|,|z|) is represented exactly as the maximum of four signed linear terminal objectives; the four component values are combined per fixed open-loop control plan before selecting the minimum.

Adaptation: the source uses continuous controls over 4 seconds. This pilot uses three 0.1-second stages, controls and disturbances in {−1,+1}, and an open-loop control plan against a full adversarial sequence. It is not a reproduction of the original RL training run. The independent checker replays the source's 100 simultaneous Euler substeps per stage.
