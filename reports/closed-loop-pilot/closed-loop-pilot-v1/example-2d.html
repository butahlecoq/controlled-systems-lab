Reproduce the saved report

This rendering uses the repository's pinned Linux CPython 3.11 lock for the runner environment. Set PYTHON to the qualified interpreter; set MPC11_VENV and MPC11_WHEELS to new directories when creating a fresh environment.

python3.11 -m venv "$MPC11_VENV"
"$MPC11_VENV/bin/python" -m pip download --only-binary=:all: --require-hashes -r benchmarks/reporting/mpc11/environment/requirements-linux-cp311.lock --dest "$MPC11_WHEELS"
"$MPC11_VENV/bin/python" -m pip install --no-index --find-links "$MPC11_WHEELS" --require-hashes -r benchmarks/reporting/mpc11/environment/requirements-linux-cp311.lock
PYTHON="${PYTHON:-$MPC11_VENV/bin/python}"
"$PYTHON" scripts/reports/render_closed_loop_pilot.py --output reports/closed-loop-pilot/closed-loop-pilot-v1
