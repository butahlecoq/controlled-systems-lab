Interior-state cost changes the chosen control

Two state coordinates and one scalar control use x[k+1]=u[k](1,1), x₀=(0,0), two stages, and u[k]∈[-1,1]. Both cases have 0.2u[k]² input cost. The red case adds an interior tracking cost at stage one, ||x₁-(1,0)||². The terminal cost is zero.

Checkable answer

On the reachable line, x₁=(u₀,u₀). The objective is (u₀-1)²+u₀²+0.2u₀²; setting its derivative to zero gives u₀=5/11. Without the state penalty the objective is 0.2u₀², so u₀=0. The plotted points match the native HiGHS run in the captured output.
