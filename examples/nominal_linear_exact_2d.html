One-step 2D nominal linear problem

Known initial state x₀=(0,0), dynamics x₁=u₀, control box [0,1]², terminal constraint x₁+y₁ ≥ 1 inside the unit square, and objective minimize x₁+y₁.

The red segment is the full optimal terminal-state face. Because x₁=u₀, it also represents the full optimal control relation. The executable constructs the problem, runs Strategy A, and requires a registry-verified complete-family result; its printed objective and scope can be checked with the command below.

cmake --build build --target nominal_linear_exact_2d
./build/examples/nominal_linear_exact_2d

Scope: finite binary64 inputs are interpreted as exact dyadic values by the profile verifier. Strategy A's forward geometry and optimization still use numerical providers; this example does not claim validated arithmetic.
