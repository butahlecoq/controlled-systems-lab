One-step forward-relevant sets

Start at x₀=(0.2,0.4). Use x₁=x₀+u₀ with the whole continuous control box u₀∈[-0.2,0.3]×[-0.1,0.2]. The physical stage-one set and terminal feasibility set are X₁=[0,0.8]×[0.1,0.9]; the terminal set is a feasibility constraint, not a target cost.

Direct addition gives F₁=[0,0.5]×[0.3,0.6]. This is inside the physical terminal set, so the backward set restricted to this forward carrier and the full-state intersection are the same rectangle. The initial intersection is the single point (0.2,0.4). For example, u₀=(0,0) reaches that point at stage one.
