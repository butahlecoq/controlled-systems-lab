## Cited-source and generator search

L05 PDF p. 12 identifies [5] as Shorikov and Goranov, *Method of approximation of the reachability region of a nonlinear controlled dynamic system*, *Applied Mathematics and Control Sciences* 2017 no. 2, pp. 112-121. The [publisher's ten-page PDF](https://ered.pstu.ru/index.php/amcs/article/download/2225/1690) matches that title, authors, year and printed pagination. Its example is a flight-dynamics/deviation model, so bibliographic recovery alone does not identify the L05 Example 1/Table 1 generator or its support-selector implementation. L05 [6] cites Bulaev's *On using the simplex method to approximate convex polytopes* (`Об использовании симплекс-метода для аппроксимации выпуклых многогранников`), 2017 Ural Power Institute young-researcher proceedings, pp. 397-399. Exact-title web search and bounded local archive filename/document search found its citation but not a primary full text. Related registered A43/A44 and local ITIS17 papers have different titles/authors/pages and remain distinct from [5]/[6]. This updates source availability after the earlier proof audit; it does not retroactively extend that audit's inspected proofs.

A strong **candidate companion**, not a Table 1 source identity, is the private `PhD/Публикации/Бурятия/Volterra.m` (SHA-256 `c26fc2424fa8b3325a864d1afbc67920ba1c05665bfdf4562bed79548b60a4f1`; a byte-identical copy is in the duplicate archive tree). Lines 4-13 set `x0=(410,300)`, `x_ref=(400,300)` for `b=a/x_ref(2)` and `d=c/x_ref(1)`, the printed parameters and 60 steps, with `T0=(2π/√(ac))/60` in this *candidate code*. Lines 16-21 build a zero-control Euler trajectory; lines 23-39 start its linear and nonlinear arrays at `(1,2)`, build time-varying `A/B`, and derive the scalar control endpoints `[-0.3,0.3]`. At line 29, the first `A` uses `x0(:,2)` through `x0(:,i+1)`, while L05 PDF p. 9 writes `A(t)` using `x̃(t)`. This is a literal indexing difference; the correspondence between code loop `i` and printed `t` is not established. Lines 45-65 advance both arrays, call `ConvSM_mod` (SHA-256 `e178858e42d5f6174d032d9415b9b7412b2e32ca9aa1b9bfbed7b202db65eaa6`) and plot every step. `ConvSM_mod` calls `Simplex_Hull_mod` (SHA-256 `6f87f2c674519352f6801df60fe498a33ac091b79a5a6cbe76f0dcf4a20f6229`). The candidate uses one active reduction path; its `Approx_mod` calls are commented. Its single `tic`/`toc` surrounds reference construction and plots. It has no explicit Table 1 volume/vertex computation, general-versus-modified comparison, saved output or separate algorithm timings. It therefore suggests a possible deviation-coordinate convention but does not reconcile the paper's physical and linear initial states or establish which code produced any Table 1 cell.

The bounded search covered the parallel `PhD/` and `Дисcертация/Дисcертация/` archive trees' likely publication/code names, DOCX text and exact-title web results. A different local 2D `main.m` (SHA-256 `4e41442776147df705d30f6fb25aeb2ff817a5c0b31285f6d5b9d227a6ea468e`) uses 48 steps, and L26/W12 use the unrelated backward fuel example; neither supplies the missing Table 1 run. Duplicate files and similarly named papers were not counted as independent source confirmation. Compressed or unnamed material outside this search could still exist.

The [source-to-experiment comparison](reachability-source-correspondence.md#direct-source-comparison) rules out treating the inspected L26 active four-state/T16 backward fuel example or its W12 near-copy as the L05 two-dimensional/T60 Table 1 run. A later check must identify a versioned Table 1 driver, full inputs and saved outputs before historical run correspondence can be asserted. This bounded inspection does not prove no such generator exists elsewhere.
