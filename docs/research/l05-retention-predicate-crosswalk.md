## Predicate readings and assurance

The L05 wording is not enough to infer an executable operation:

1. **Equality to a current facet.** This is an overly narrow reading. The exact example in the [proof audit](reachability-proof-audit.md#4-support-hyperplane-wording-scoped-counterexample-not-an-unconditional-attribution) has a new extreme point outside the current hull that lies on none of its existing facet hyperplanes. Discarding it loses part of the processed-point hull.
2. **Membership in some support hyperplane of the current hull.** The prose does not specify a finite test for this reading. A separating support hyperplane may pass through an exterior point, so the wording alone does not define a safe discard rule.
3. **Vertexhood of the enlarged hull.** Testing whether the point is extreme in `conv(S ∪ {q})` is a distinct, well-defined operation. The related A44 source uses an enlarged-hull test, but the [source authority section](reachability-proof-audit.md#source-authority-and-review-disposition) explicitly keeps A44 separate from L05's cited [5]/[6] and does not identify it as the Table 1 implementation.
4. **Hash-identified candidate simplex filter.** The `Volterra`/`Dim4` path is directly observable in the candidate source and can be replayed for bounded fixtures. It is not mapped to any one of the printed interpretations by the available source record, and its binary64 replay is not a proof about another revision or the historical run.

The four-state replay is particularly discriminating: the active candidate path yields the printed general-row count and volume, while the commented approximation hypothesis does not yield the printed modified row. That rules out attributing the modified row to those inspected active/commented paths on the checked input. It does not select a different historical implementation by elimination.

The separate [T0 grouping check](evidence/l05-t0-grouping.json), merged through [issue #534](https://github.com/butahlecoq/controlled-systems-lab/issues/534), selects the grouping that matches the saved Example 1 figures for the hash-identified `Volterra.m` candidate. This is candidate-to-figure evidence only. It does not recover the article's Table 1 driver or turn the candidate's retention filter into a historical source identity.

Keep the reported Table 1 values unchanged and keep issue #4 open until its remaining source and enclosure obligations have evidence.
