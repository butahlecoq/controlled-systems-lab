# Issue #1 fuller-dissertation archive follow-up

This note records a bounded, read-only comparison of two supplied dissertation collections. `phd-archive` is the extraction of `PhD.zip` (SHA-256 `d13b82f848002137cfab4682f1d6f69b9411b360f4078dec27fa0f54566c8453`). `dissertation-working-collection` is the separate fuller dissertation copy. The owner described that copy as probably newest; this comparison does not establish revision chronology. It adds source-version evidence for L04 but does not reproduce a publication run or close [issue #1](https://github.com/butahlecoq/controlled-systems-lab/issues/1).

## A distinct manuscript revision contains the published L04 linear row

The `phd-archive` collection contains the 37,412-byte AaRC manuscript already described in the [source and criterion version trace](issue1-source-version-trace.md). The `dissertation-working-collection` contains a different 38,966-byte file at the same relative path, `Публикации/Минимакс/Unconstrained for AaRC/Paper/Shorikov_Kalev_AiT.tex`, SHA-256 `b1cbcac49b50282784ba9819fa792ae9c09b0049faa0e694da65ec89a9962891`.

The 38,966-byte content variant reports the four-stage control `{0.6, 0.6, -0.3, 0}` with linear result `67.12` and state `(1201.139, -27.294, 452.606, -61.254)`. It also retains nonlinear state `(1200.139, -2.294, 450.406, -16.254)` and reported value `14.048`. The text and Table 2 entry are at lines 338 and 358–360. By comparison, the previously recorded 37,412-byte variant reports linear value `56.433` with state `(1200.939, -32.294, 451.206, -46.254)`. The distinct text identifies two manuscript content variants. File size and hash do not establish their chronological ancestry or identify the code and run behind either row.

The `dissertation-working-collection` also contains `Публикации/Минимакс/Unconstrained for AaRC/tex/Shorikov_Kalev_AиT_New.tex` (39,898 bytes; SHA-256 `6a79451d2be9ca9a9d4caaab288bf3761cfab200f7729e6d7e54662511b948a5`). The PhD archive has a different file at this path. The recorded 39,898-byte variant retains the same published `67.12` row. It is another manuscript variant, not independent proof of the numerical result.

## Newly located MATLAB files remain candidates

The `dissertation-working-collection` has an L04-scale source pair under `Публикации/Минимакс/Unconstrained for Space Research/`. `Minmaxopenloop.m` (3,689 bytes; SHA-256 `d997f0479413d452e7ef6e1673c4cace47f627b0a4e611ef014480f6070534cd`) uses initial state `(1182.074, 119610, 459.832, 45220)`, four stages, actions `{0.6, 0.3, 0.01, -0.3, -0.6}`, stage-indexed disturbance vertices, and a Euclidean terminal score. `program.m` (1,290 bytes; SHA-256 `3125634e0c60d02e93984de1a37e81c2df9f4504e19925764701aad09b6759fd`) replays a selected control sequence in the nonlinear model. Its printed `J` expression has an unsquared `(mg(end)-450)` term. The PhD archive has no files at these paths. These files do not include an attributable output or row-to-run record, and their stated initial state and action set differ from the published L04 setup.

The adjacent `second.fig` in `dissertation-working-collection` (514,923 bytes; SHA-256 `a5116458f760dca192f21d5a0091685d2a43717e0329d91c6a660a1862994b02`) stores endpoint `(1200, 7.298699236853281, 450, 12.003255432742662)`. The PhD archive has no file at this path. The endpoint does not match the printed nonlinear L04 state, and it does not establish that the nearby program generated the figure.

The `Публикации/Минимакс/Constrained/Minmaxopenloop.m` file in `dissertation-working-collection` (3,243 bytes; SHA-256 `0f650a7db58028d7479644546094067268d87f79bcad8c9653408c97175d5c9d`) uses `X0=(1182.074, 119610, 459.832, 45220)`, four stages, actions `{0.6, 0.3, 0.01, -0.3, -0.6}`, `B=(2208/110, 0, -1152/110, 0)`, a fixed disturbance generator `W` with entries `0.4` and `-0.4`, and a Euclidean terminal score. At each stage, it also rejects states outside the fixed inequalities `da*X<=db`. The PhD archive has a different file at this path. Compared with published L04, this source uses stocks `119610` and `45220` instead of `119560` and `45260`, action `0.01` instead of `0`, a slightly different exact `B`, and fixed disturbance vertices instead of the published stage-dependent disturbance bounds. The source does not establish that it generated the published row, and it does not recover the nonlinear `14.048` calculation.

## Search result and remaining evidence

A read-only scan compared 129 unique `.fig` and `.mat` file identities across the two trees. It summarized trajectories whose first endpoint coordinate was within three units of 1200, 450, 60, or 24. No scanned saved-figure endpoint matched the printed L04 nonlinear state. Two parse errors came from AppleDouble `._` metadata files. The scan used SciPy's MAT reader and binary64 summaries; it was a bounded filename-based scan, not an inspection of every archive, document, or embedded project.

The source update is specific: the fuller tree contains a manuscript variant with the published linear `67.12` row and additional MATLAB candidates. The nonlinear displayed state and `14.048` remain unexplained, and neither the matching manuscript nor the candidate programs link a source revision to a saved optimization run. The next useful evidence is the original criterion implementation with its unrounded run arrays and output, or an attributable author statement linking a source revision and run to the L04 table. The separate L13 Figure 3/A08 candidate chain is already documented in the existing [source trace](issue1-source-version-trace.md) and is not repeated here.

The [machine-readable source record](evidence/issue1-dissertation-archive-followup.json) binds each recorded hash to a collection ID and `collection_relative_path` where those exact bytes were verified. It records the ZIP hash only for `phd-archive` and contains no private source files.
