# Fixed-plan disturbance and worst-case numerical reference

EXT-01 / issue #62. The public interfaces are
[`fixed_plan_disturbance.hpp`](../../include/csl/reachability/fixed_plan_disturbance.hpp)
and [`worst_case_vertex.hpp`](../../include/csl/optimization/worst_case_vertex.hpp).
They are native numerical references for a **fixed control plan**, not a
finite-action search, causal feedback policy, optimal-family publisher, or
validated-arithmetic certificate.

## Admission and result

`fixed_plan_disturbance` accepts an immutable affine `LinearSystem`, a compact
native V or singleton initial set, one compact native V or singleton
disturbance set per transition, one fixed control vector per transition, and
one convex H, singleton, universal or empty admissible-state set per state
stage. The caller supplies a distinct nonempty request ID for each fixed plan,
which is included in generated stage-set IDs. Disturbances are independent
across stages. The caller caps generated
points per stage. The module generates every pair of previous candidate and
current disturbance vertex. It applies the model's `A x + B u + E w + a`
transition, then checks **every** successor against the next state set. A
whole-request preflight checks all stage representations, boundedness, dimensions
and candidate growth before any propagation, so a later unsupported input or
capacity limit is not hidden by an earlier robust violation. A
violating successor returns `FixedPlanViolation` with its stage and coordinates;
the module never clips it away. An empty initial/disturbance description
returns `FixedPlanEmpty`. Unsupported representations, mismatched dimensions,
invalid inputs and capacity limits return typed `Unsupported`; cancellation,
deadline and arithmetic failure return `OperationStopped`. None of these
failure variants contains a completed reachable tube.

Each returned stage after zero is a native V description containing all
generated candidates. Redundant candidate rows are retained. Under the
declared affine, independent, convex-set assumptions, its convex hull is the
complete reachable set for that fixed plan: affine maps preserve convex hull,
and the product of two finite convex hulls is generated by all vertex pairs.
For a convex H safe set, testing all candidate vertices tests whole-set
containment. The returned tube carries `Assurance::numerical`; tolerance-based
membership and binary64 transitions are not validated enclosures. This
argument does not apply to nonlinear dynamics, correlated
disturbances, nonconvex constraints, feedback control or uncertain model data.

`worst_case_vertex` accepts one bounded native V set or singleton, a frozen
`Objective`, and a vertex count limit. A convex objective attains its maximum
over a compact polytope at an extreme point. The module evaluates every
authored V row, including redundant ones, and returns the largest evaluated
value and one maximizing row. `WorstCaseEmpty` denotes an empty set. H-only,
unbounded and over-capacity inputs return `Unsupported`; numerical failures
and execution stops remain distinct. A quadratic `Objective` is accepted only
after the existing objective snapshot's numerical PSD admission. The result's
assurance is explicitly `numerical`: binary64 evaluations and PSD checks do
not prove a validated global rounding enclosure. A V description's row
semantics establish its mathematical set, but this module does not verify
that the rows are equivalent to an independent H/source description. Such
conversion evidence belongs to the selected geometry provider.

## Reference checks

The unit tests assert the archived L19 counterexample: `(x-1)^2` on `[0,2]`
has worst value `1` at an endpoint, despite its stationary midpoint value
`0`. A two-step integrator test retains all four disturbance histories and
rejects a plan when a safe-set intersection is nonempty but whole-set
containment fails. The displayed rounded B08 model is tested by enumerating
all 625 four-action plans and each plan's 256 disturbance-corner histories.
The numerical minimum is approximately `67.150601101407` with three ties at
absolute tolerance `1e-8`, matching the independent saved discrete reference
in [`reference-b08.json`](../research/reference-b08.json). The published
`67.12`, nonlinear trajectory result, original unrounded MATLAB arrays,
historical timing and validated rounding remain separate and unreproduced.
