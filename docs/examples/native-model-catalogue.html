Native C++ models · forward reachability · three states

From a mathematical model to reachable sets in C++

The catalogue constructs the model, initial region and admissible inputs as native CSL objects. This first example uses the complete numerical model on slide 33 of Shorikov and Bulaev’s 2016 presentation. It has three abstract state coordinates and one input; the source supplies no physical units or optimization objective.

The model

xk+1=Axk+Buk A=[100010−3−40] B=[320]
X0=[−0.5,0.5]×[−1,1]2,uk∈[−3,1]

The initial state is a box, rather than a selected point. Every stage has an independent input interval. Its generator form has centre −1 and half-width 2, so the asymmetry of the original input bounds is preserved.

The source contains two horizon conventions: its printed update range 0 through 7 gives eight transitions, while its figures show sets at stages 1 through 7. The catalogue retains separate literal-eight and illustrated-seven cases. Times are integer stage indices; no physical sampling period is inferred.

All stages, from the full three-dimensional calculation

The native executable propagates the complete generator sets, materializes their V descriptions and checks every initial/input corner against the independently written scalar equations. Projection happens afterward. Colours identify the stage; the plots show only forward reachable sets, with no invented target or optimal trajectory.

The unreduced zonotope and the convex hull of the materialized V points describe the same affine reachable set in real arithmetic. The CSV retains all cube-corner images, including duplicates and redundant points; it is not a list of minimal hull vertices. This example supplies an exact affine reference for later recursive approximation comparisons. It does not yet compare all approximation families or establish a general floating-point inclusion guarantee.

Use the native case

#include <csl/model/catalogue.hpp>
#include <csl/model/linear_system.hpp>

auto data = std::get<csl::model::catalogue::DiscreteReachabilityCase>(
    csl::model::catalogue::make_discrete_reachability_case(
        "bulaev-2016-slide33/illustrated-seven/1"));
auto system = csl::model::snapshot(data.model, data.time_grid);

data.initial and each entry of data.controls are native generator sets. The input factor IDs differ between stages. The example uses the registered affine-image and independent Minkowski-sum operations, bounded generator-to-V conversion and the public 2D QuickHull for projected boundaries. The catalogue does not own a replacement reachability algorithm.

cmake -S examples -B build/native-model-examples \
  -DCSL_DIR=/path/to/install/lib/cmake/CSL
cmake --build build/native-model-examples --target native_model_catalogue
build/native-model-examples/native_model_catalogue --list
build/native-model-examples/native_model_catalogue new-output-directory

The output directory must be new. Model construction, propagation, checking and SVG/CSV production need no Python, HiGHS or Qhull. The installed C++ package and compiler remain required.

Two located copies are byte-identical. Their SHA-256 is 029d55dd5b2d2ff1682bb42ffead7e2f5f0133df78864ae5ee583028200a88e5. The private original files are not redistributed.
