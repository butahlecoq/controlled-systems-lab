Native C++ · saved functional evidence

Observe, predict, apply one action: native 12-state MPC

At each of 15 observed states, a native C++ client solves a ten-transition quadratic problem, applies only its first four-component action, and observes the resulting next state. The client uses CSL’s registered HiGHS convex port. These figures read the saved successful functional capture; rendering runs no solver.

One source model, one explicit task

This is model 21’s A and B from the official OSQP MPC example, executed with HiGHS. Indices here are one-based: x₁ is source x[0]. The official page does not establish semantic names or physical units for every coordinate. The owner catalogue assigns a nominal 0.1-second grid; that time interpretation is an owner assumption, not recovered from the official page. State plots therefore use absolute stage indices.

Every prediction and the actual executed path

Each blue polyline contains all 11 states of one predicted plan. The green path contains the initial observation and all 15 executed next states. Square, diamond, and star mark the initial state, final executed state, and reference projection. A reference is an objective point, not a terminal feasibility set. Two-dimensional projections hide the remaining coordinates and do not represent reachable sets.

The (x₁, x₂) plane is shown at its stated constraint scale ±π/6: all values are within 1.7 × 10⁻¹³ of zero, so its markers overlap. This symmetry is not evidence of missing stages. The (x₃, x₆) plane exposes the reference-tracking transient. The axes have independent scales because their physical units are unspecified.

Check the saved result and reproduce the client

The separate Python replay checks every saved coordinate, initial/observed state, applied first action, zero-input transition, stated bound, and literal source cost. Maximum absolute residuals are 3.58 × 10⁻¹⁴ (objective), 7.47 × 10⁻¹³ (predicted dynamics), and 4.44 × 10⁻¹⁶ (executed step). The 15-stage realized running cost is 28.0588822368079, with no terminal term; it is not any one ten-stage plan’s objective.
