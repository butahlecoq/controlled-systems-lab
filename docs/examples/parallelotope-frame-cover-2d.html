A rotated frame can enclose a diamond exactly

A certified parallelotope membership is x = frame · factor with one independently certified interval per frame column. The frame rule chooses those columns. On the diamond |x+y| ≤ 1, |x−y| ≤ 1, the identity frame can only produce the bounding box, while the fixed 45° frame aligns its columns with the facet normals and the cover collapses onto the set itself.

Both covers come from bounded_h_frame_cover: each frame column and side is one support LP solve over the same bounded H intersection, so a cover costs 2·dimension solves and the deterministic support-selected rule that measures both candidates costs 4·dimension. The certificate for every bound is the dual-feasible support optimum with its residual correction; nothing here is sampled.

The width product is the enclosure volume for orthonormal frames, which is the selection measure. On this set the rotated cover wins 2 < 4; select_parallelotope_frame keeps candidate zero, the axis frame, whenever the products tie, so a rotation is never forced when the axis frame is already tight. On an axis-aligned box the same rule retains the axis frame.
