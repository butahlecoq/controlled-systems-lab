Why the full history changes the chosen control

With one step, the state and control coordinates coincide at the terminal time: x₀=(0,0), x₁=x₀+u=u. The feasible history is the whole control square [-2,2]². The orange point is the terminal-only optimum. The green point is the actual result returned by the registered csl.convex.highs QP provider for the compiled full-history objective.

Objective and answer

Jterminal(u)=‖u−(1,0)‖²

Jfull(u)=‖u−(1,0)‖²+2‖u‖²

Expanding gives Jfull(u)=3‖u−(1/3,0)‖²+2/3. Thus the analytic minimizer is (1/3,0); the saved native QP response returns (0.33333333333333304,0).

The complete feasible history

Use the canonical block vector z=[x₀ᵀ, x₁ᵀ, u₀ᵀ]ᵀ∈ℝ⁶. The source-complete feasible relation is

[ I　0　0 ; −I　I　−I ] z = [ 0 ; 0 ],   [ 0　0　I ; 0　0　−I ] z ≤ [ 2,2,2,2 ]ᵀ.

Here each block is 2×2, I is the identity, x₀=(0,0), and the second equality is x₁=x₀+u₀. The inequalities are exactly u₀∈[−2,2]², so the full projection onto the control plane is the square shown above.

Source and saved native evidence

The native response records a one-step, two-state, two-control canonical history vector [x₀,x₁,u₀], four equality rows for x₀=0 and x₁=x₀+u₀, and four box inequalities for u₀∈[-2,2]². The total-cost request includes the running quadratic before solving; terminal-only is a separate request.
