Four-state reachable sets from a printed linear model

This numerical comparison case comes from the 2017 author manuscript by Bulaev, Goranov and Kalyov, “Constructing optimal programmed control for complex mechanical objects”. Its final example supplies a discrete four-state system, an uncertain initial box and one independent input at every step. The comparison example supplies no optimization objective.

The source data

xk+1=Axk+Buk,k=0,…,14
A=[100.0300.01410.00010.030.11401−0.00020.91500.0141] B=[−0.00240.0051−0.1570.339]
X0=diag(0.052,5,0.018,1)[−1,1]4 uk∈[−0.14,0.14]

The box bounds apply to x(0). They are not imposed on subsequent states. The printed updates 0 through 14 and the table’s stages 1 through 15 agree: this case has 15 transitions. State coordinates and the sampling period have no declared physical units in this comparison; the native case keeps integer stages and the printed numbers.

All sixteen sets on each plane

The computation propagates the full four-dimensional generator set. The two planes are selected only afterward. Each input receives a fresh factor ID; at stage 15 the unreduced set has 19 generator factors: four initial factors and fifteen independent inputs.

The projected boundary is constructed with repeated two-dimensional segment sums and the existing native QuickHull. Its saved full-state witnesses belong to these projection boundaries; their union is not a full four-dimensional V representation. The complete four-dimensional result is preserved as centre and generator matrices.

An independent support check

For a direction d, the independent native checker works backward through the printed matrix. It adds the support of every input interval and finally evaluates the initial box:

hXk(d)=hX0((Ak)Td)+∑j=0k−10.14|dTAjB|

The saved run passes 1,280 full-state support checks and 2,048 checks of the projected boundaries. It compares the printed-decimal reference calculation with binary64 generator propagation using a declared numerical tolerance. Finite directional checks are numerical evidence, not a general certified inclusion proof. No full 2¹⁹-corner materialization, controller result or speed comparison is claimed.

Use and reproduce the native case

auto data = std::get<csl::model::catalogue::DiscreteReachabilityCase>(
    csl::model::catalogue::make_discrete_reachability_case(
        "archival-2017-4d-scalar-reachability/1"));
cmake -S examples -B build/native-model-examples \
  -DCSL_DIR=/path/to/install/lib/cmake/CSL
cmake --build build/native-model-examples --target native_four_state_reachability
build/native-model-examples/native_four_state_reachability new-output-directory

The C++ executable constructs the model, propagates the sets, checks supports and generates the CSV and screen/print SVG files. No Python environment, HiGHS or Qhull is required for this path.
