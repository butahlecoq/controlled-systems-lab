# Separate CPU profile summary

This is a separate user-space CPU profile of the exact Release binary used for the analytic sample (binary SHA-256 in the adjacent environment capture). The raw `perf.data` file is retained alongside it.

- Tool: Linux `perf` 7.2.3-1, unpacked under `/tmp` from the configured Arch package mirror; no system package was installed.
- Command: `perf record -F 999 -g -o <profile> -- ./build/obs04/csl_obs04_instrumentation_comparison`.
- Event: user-mode CPU cycles; kernel and hypervisor samples excluded.
- Result: 167 samples over 145.794 ms; zero lost samples.
- Top self symbols: `free` 7.55%, `malloc` 7.52%, C++ string assignment 2.84%, `operator new` 2.58%, `operator delete` 1.97%, and `HighsLp` destruction 1.46%. Some samples resolve only to binary offsets because this Release build has no debug line tables.

This profile covers the whole driver process: initialization, the analytic baselines, workspace/collector setup, strategy calls, and collector snapshots. It does not isolate the timed `StrategyPort::run` intervals. The visible allocation/cleanup and solver symbols do not establish a unique bottleneck for the measured intervals. Treat the comparison as inconclusive; do not infer that instrumentation overhead is caused by allocation or claim a general limiter.
